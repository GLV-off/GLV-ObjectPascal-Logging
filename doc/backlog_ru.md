# Бэклог GLV Log

Проверяемый список долгов, найденных `code-recon` и сессиями S1–S4.
Один пункт = одно осмысленное изменение + один тест (или явное решение).
Правила полей и статусов — `.pi/skills/backlog-from-review/references/item-template.md`.

- `next` — 5 ближайших пунктов; `later` — остальное; `inbox` — новые строки
  от `findings-to-backlog.sh`.
- `путь:строка` — доказательство на момент добавления; при закрытии обновить.
- `done` ставится только после теста или явного решения; `wontfix` — только
  с причиной.
- Пункты с `API` в риске дороже: их нельзя закрывать «заодно» с другими.
